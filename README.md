# Лабораторная работа №10-11: 

## Название проекта
**Student Material Design** — приложение для отображения списка студентов с использованием Material Design.

## Цель работы
Изучение принципов Material Design в Android-приложениях с использованием Jetpack Compose: цветовые схемы, типографика, формы и анимации.

## Функциональность
- Отображение списка студентов (10 человек)
- Карточка студента с фото, именем и возрастом
- Раскрывающееся описание при клике на иконку ▼/▲
- Плавная анимация раскрытия/сворачивания
- Поддержка светлой и тёмной темы
- Верхняя панель с логотипом и названием

## Технологии
- Jetpack Compose
- Material Design 3
- Кастомные цвета (зелёная тема)
- Кастомные шрифты (Abril Fatface, Montserrat)
- Кастомные формы (круглые аватарки, скошенные карточки)
- Анимации (spring animation)
